# 复杂 C 声明的阅读方法

## 核心观点

阅读复杂 C 声明时，应从标识符附近开始向外读，同时注意 `[]` 的优先级高于 `*`；括号的位置会改变声明的含义。

## 解释

```c
int (*A3)[3];
```

阅读为：`A3` 是一个指针，它指向一个包含 3 个 `int` 的数组。

```c
int *A4[3];
```

阅读为：`A4` 是一个包含 3 个元素的数组，每个元素都是 `int *`。

二者的区别：

```text
int (*A3)[3]  // 指向数组的指针
int *A4[3]    // 指针数组
```

## 例子 / 推导

```text
sizeof(A3)    = 8
sizeof(*A3)   = 12
sizeof(**A3)  = 4

sizeof(A4)    = 24
sizeof(*A4)   = 8
sizeof(**A4)  = 4
```

这里采用典型 x86-64 环境：指针 8 字节，`int` 4 字节。
