# 这个知识库怎么用

这是一个面向计算机基础学习的 Obsidian 知识库，采用轻量版 Zettelkasten + PARA。

## 文件夹规则

- `0-Inbox`：临时捕捉。允许乱，但每条内容在 48 小时内处理。
- `1-Projects/CSAPP`：当前项目《深入理解计算机系统》的章节笔记、实验和进度。
- `2-Areas`：长期经营的领域，例如「计算机底层基础」。
- `3-Resources`：暂时不深入的参考资料。
- `4-Archive`：不再活跃的内容。
- `Maps`：MOC 知识地图。某个主题的永久笔记达到约 20 条后再建立。
- `Templates`：笔记模板。
- 仓库根目录：永久笔记。依靠 `[[双向链接]]` 连接，而不是继续增加文件夹。

## 每次学习的最小流程

1. 读书或做实验时，先在 `0-Inbox` 快速记录疑问和灵感。
2. 每章结束后，用 `Templates/CSAPP章节笔记.md` 建一篇文献笔记。
3. 把能独立解释的概念加工成永久笔记，放在仓库根目录。
4. 新建永久笔记时，至少链接一条已有笔记；没有合适链接时，记录「待连接」。
5. 每周花 15~30 分钟清理 Inbox，不做大规模迁移。

## 三条防混乱规则

- 不为每个概念预先建文件夹。
- 永久笔记不照抄，必须用自己的话讲清楚。
- 标签只表达状态，例如 `#待消化`，不代替链接和 MOC。

## 推荐起点

先创建第一张永久笔记：`局部性.md`。

可以从这句话开始：

> 程序访问数据和指令时，往往会在短时间内重复访问附近的位置；这种规律让小而快的缓存能够有效提升整体性能。

然后继续补充：时间局部性、空间局部性，以及它们和存储器层次结构的关系。
