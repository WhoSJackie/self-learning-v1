# 浮点数的舍入误差

## 核心观点

浮点数的位数有限，理想数学结果往往不能精确保存，计算机必须把结果舍入为目标格式中可表示的近似值。

## 解释

IEEE 754 默认采用“向最近偶数舍入”：选择距离最近的可表示值；如果刚好位于两个候选值中间，选择最低有效位为偶数的那个。

浮点数的间距不是处处相同：数值越大，相邻可表示数之间的绝对间距通常越大。因此浮点数更接近“相对精度大致稳定”，而不是“绝对误差固定”。

## 例子 / 推导

```c
float f = 16777217;
```

单精度通常只有 24 位有效二进制精度，无法精确保存 `2^24 + 1`，因此 `f` 可能被舍入为 `16777216`。

浮点运算可能出现：

```text
0.1 + 0.2 != 0.3
```

这里不是数学规则错误，而是参与运算的值可能已经是近似表示。
