# 二进制小数表示

## 核心观点

二进制小数点右侧的每一位表示负的 2 的幂。有限位二进制小数只能精确表示形如 `x / 2^k` 的数，因此很多十进制小数只能近似表示。

## 解释

```text
101.11₂ = 1×2² + 0×2¹ + 1×2⁰ + 1×2⁻¹ + 1×2⁻²
        = 5.75
```

`1/3`、`1/5` 和十进制 `0.1` 的二进制展开通常是无限循环的。计算机只有有限位数，所以必须截断或舍入。

浮点数的设计就是利用指数移动二进制小数点，在有限位数下平衡可表示范围和精度。

## 例子 / 推导

```c
0.1 + 0.2 == 0.3
```

这个表达式通常不能直接认为为真，因为 `0.1`、`0.2` 和 `0.3` 可能分别被保存为不同的近似二进制值。
