# C 语言浮点类型转换

## 核心观点

整数、`float` 和 `double` 之间转换时，可能发生精度损失、舍入、截断、溢出或下溢；转换顺序也会改变表达式结果。

## 解释

- `int -> float`：目标精度有限，可能舍入。
- `int -> double`：在常见范围内通常可以精确表示。
- `float -> double`：通常不会损失 `float` 已有的精度，但不能恢复之前丢失的信息。
- `double -> float`：可能舍入、溢出或下溢。
- `float -> int`：通常朝 0 截断。

```c
(int)3.9   // 3
(int)-3.9  // -3
```

## 例子 / 推导

```c
(float)(a / b)       // 先整数除法，再转 float
(float)a / (float)b  // 先转浮点，再做浮点除法
```

```c
5 / 2      // 2
5.0 / 2    // 2.5
```

单精度通常只有 24 位有效二进制精度，因此：

```c
float f = 16777217;
```

可能无法保存精确的 `16777217`。
