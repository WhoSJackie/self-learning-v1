# 二维数组是数组的数组

## 核心观点

C 语言中的二维数组不是特殊的矩阵对象，而是“数组的数组”：

```c
int A[3][5];
```

表示一个包含 3 个元素的数组，而每个元素又是包含 5 个 `int` 的数组。

## 解释

二维数组在内存中连续存储，并采用行优先顺序：先存储第 0 行，再存储第 1 行，依此类推。

```text
A[0][0], A[0][1], ..., A[0][4],
A[1][0], A[1][1], ..., A[1][4],
A[2][0], A[2][1], ..., A[2][4]
```

如果列数为 `N`，元素类型大小为 `sizeof(T)`，那么 `A[i][j]` 相对首地址的字节偏移为：

```text
(i × N + j) × sizeof(T)
```

## 例子 / 推导

```c
int A[4][6];
```

对于 `A[2][3]`：

```text
元素序号 = 2 × 6 + 3 = 15
字节偏移 = 15 × 4 = 60 字节
```
