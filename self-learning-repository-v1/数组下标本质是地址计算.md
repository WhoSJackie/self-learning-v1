# 数组下标本质是地址计算

## 核心观点

在机器层面，数组下标访问可以还原为：

```text
元素地址 = 基地址 + 索引 × sizeof(元素类型)
```

因此 C 语言中的：

```c
A[i]
```

等价于：

```c
*(A + i)
```

## 解释

`A + i` 并不是把机器地址简单增加 `i` 个字节。指针运算会根据指向类型进行缩放：如果 `A` 是 `int *`，那么 `A + i` 的地址偏移就是 `i × sizeof(int)`。

例如：

```c
int A[5];
```

假设 `A` 的首地址为 `x`，由于 `int` 占 4 字节：

```text
A[0] 的地址 = x
A[1] 的地址 = x + 4
A[2] 的地址 = x + 8
```

这也是 x86-64 缩放寻址能够高效实现数组访问的原因。

## 例子 / 推导

```c
int get(int *p, int i) {
    return p[i];
}
```

逻辑上相当于：

```text
从地址 p + i × 4 处读取一个 int
```
