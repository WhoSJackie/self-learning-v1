# 数组和指针不是一回事

## 核心观点

数组和指针经常可以用相似的语法访问，但它们代表不同的对象：数组是一段实际的连续存储空间，指针是保存地址的变量。

## 解释

```c
int A[3];
int *p;
```

`A` 会分配 3 个 `int` 的空间，典型环境下为 12 字节；`p` 只分配指针变量本身的空间，典型 x86-64 环境下为 8 字节。指针是否指向有效对象，还取决于它是否被正确初始化。

在很多表达式中，数组名会转换为指向首元素的指针，所以：

```c
A[i] == *(A + i)
```

但这不表示数组和指针完全相同：数组名不能执行 `A++`，而指针可以移动。

## 例子 / 推导

```c
sizeof(A);   // 整个数组的大小：12
sizeof(p);   // 指针本身的大小：8
sizeof(*A);  // 元素 int 的大小：4
sizeof(*p);  // 所指向类型 int 的大小：4
```

具体大小依赖平台和数据模型。
