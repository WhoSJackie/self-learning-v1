## 核心主线

机器代码没有“数组”这个高级概念。数组、结构体等聚合数据在机器层面都可以理解为连续的一段字节；C 编译器把数组访问翻译成地址计算、加载和存储：

```text
元素地址 = 基地址 + 索引 × sizeof(元素类型)
```

例如访问 `int` 数组的第 `i` 个元素，就是基地址加上 `i × 4` 字节。x86-64 的缩放寻址可以直接表达这类计算。

## 关键概念

### 1. 数组下标就是指针运算

```c
A[i] == *(A + i)
```

如果 `A` 是 `int *`，`A + i` 的实际地址偏移是 `i × sizeof(int)`，而不是简单增加 `i` 个字节。

```c
int val[5];
&val[2] == val + 2
```

### 2. 指针运算按元素大小缩放

```c
char *cp;  // cp + 1：地址增加 1 字节
int *ip;   // ip + 1：地址增加 4 字节
```

一般规则：

```text
p + i = 原地址 + i × sizeof(*p)
```

### 3. 数组和指针不是一回事

```c
int A[3];  // 分配 3 个 int，共 12 字节
int *p;    // 只分配指针变量本身，典型环境下为 8 字节
```

数组名在很多表达式中会转换为指向首元素的指针，但数组本身代表一段实际存储空间，指针只是一个保存地址的变量。数组不能执行 `A++`，指针可以移动。

### 4. `sizeof` 可以帮助区分数组和指针

```c
int A[3];
int *p;

sizeof(A);   // 12
sizeof(p);   // 8
sizeof(*A);  // 4
sizeof(*p);  // 4
```

具体大小依赖平台和数据模型；上面是课程所采用的典型 x86-64 环境。

### 5. C 语言不检查数组边界

```c
int a[5];
a[5] = 10;  // 越界写，未定义行为
```

越界访问可能读到其他对象、破坏内存、访问非法地址或导致 segmentation fault。特别要警惕越界写，因为它可能覆盖其他变量或控制数据。

### 6. 指针数组与指向数组的指针

```c
int (*A3)[3];  // A3 是指针，指向包含 3 个 int 的数组
int *A4[3];    // A4 是数组，包含 3 个 int * 元素
```

读复杂声明时，从标识符附近开始向外读，并注意 `[]` 的优先级高于 `*`。

```text
sizeof(A3)    = 8
sizeof(*A3)   = 12
sizeof(**A3)  = 4

sizeof(A4)    = 24
sizeof(*A4)   = 8
sizeof(**A4)  = 4
```

### 7. 多维数组是数组的数组

```c
int A[3][5];
```

它表示 3 个元素的数组，每个元素又是包含 5 个 `int` 的数组，总大小为：

```text
3 × 5 × sizeof(int) = 3 × 5 × 4 = 60 字节
```

C 语言采用行优先顺序存储：先完整存储第 0 行，再存储第 1 行，最后存储第 2 行。

```text
A[0][0], A[0][1], ..., A[0][4],
A[1][0], A[1][1], ..., A[1][4],
A[2][0], A[2][1], ..., A[2][4]
```

对于列数为 `N` 的二维数组，`A[i][j]` 的地址偏移为：

```text
(i × N + j) × sizeof(元素类型)
```

## 典型例子

### 数组访问与 x86-64 缩放寻址

```c
int get(int *p, int i) {
    return p[i];
}
```

逻辑上需要计算：

```text
p + i × 4
```

在常见的 x86-64 System V 调用约定中，`p` 通常位于 `%rdi`，`i` 通常位于 `%rsi`，因此地址计算可理解为：

```text
%rdi + %rsi × 4
```

### 数组元素自增

```c
void increment(int *a, int i) {
    a[i]++;
}
```

机器层面需要计算元素地址、读取数据、加 1 并写回；x86 可以使用以内存为目的操作数的算术指令完成这一类操作。

## 一句话总结

> 数组访问的本质是“基地址加索引乘元素大小”；理解这个地址计算，同时区分数组、指针、指针数组和指向数组的指针，就能把 C 语言的数据访问和 x86-64 机器代码连接起来。
