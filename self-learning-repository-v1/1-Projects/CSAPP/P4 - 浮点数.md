- 二进制小数如何表示？

## 核心主线

浮点数借鉴科学计数法，用有限的位数同时表示数值的范围和精度：

```text
V = (-1)^s × M × 2^E
```

IEEE 754 将一个浮点数编码为：

```text
sign | exponent | fraction
```

其中 exponent 负责表示二进制小数点的位置，fraction 负责保存有效数字。浮点数不是实数的精确集合，而是一个有限、离散、带舍入误差的数值集合。

## 关键概念

### 1. 二进制小数

二进制小数点左侧表示 `2` 的非负幂，右侧表示 `2` 的负幂：

```text
101.11₂ = 1×2² + 0×2¹ + 1×2⁰ + 1×2⁻¹ + 1×2⁻²
        = 5.75
```

有限位二进制小数只能精确表示形如 `x / 2^k` 的数。`1/3`、`1/5`、十进制 `0.1` 等通常是无限循环二进制小数，只能近似保存。


### 2. IEEE 754 的三部分

```text
| sign | exponent | fraction |
```

- `sign`：`0` 表示正数，`1` 表示负数。
- `exponent`：使用偏置编码保存实际指数。
- `fraction`：保存有效数字的小数部分。

常见格式：

| 类型 | 总位数 | sign | exponent | fraction | bias |
|---|---:|---:|---:|---:|---:|
| `float` | 32 | 1 | 8 | 23 | 127 |
| `double` | 64 | 1 | 11 | 52 | 1023 |

### 3. 规格化数

当 exponent 既不全为 0，也不全为 1 时，是规格化数：

```text
V = (-1)^s × (1.fraction)₂ × 2^(Exp - Bias)
```

前导 `1` 不需要实际存储，这就是隐含前导 1。以单精度为例，`Bias = 127`。

例如：

```text
100.01₂ = 1.0001₂ × 2²
```

### 4. 非规格化数

当 exponent 全为 0 且 fraction 不全为 0 时，是非规格化数：

```text
V = (-1)^s × (0.fraction)₂ × 2^(1 - Bias)
```

它没有隐含前导 1，主要用于表示非常接近 0 的数，让数值从最小规格化数平滑地过渡到 0。exponent 和 fraction 都为 0 时，表示 `+0` 或 `-0`。

### 5. 无穷大和 NaN

| exponent | fraction | 含义 |
|---|---|---|
| 全 1 | 全 0 | `+∞` 或 `-∞` |
| 全 1 | 非 0 | NaN |

无穷大常见于浮点溢出或除以零；NaN 表示没有有效实数结果，例如 `0/0` 或 `∞ - ∞`。NaN 与任何数比较都为假，判断 NaN 应使用 `isnan()`。

### 6. 舍入

浮点运算通常先得到理想数学结果，再舍入为目标格式中可表示的值。IEEE 754 默认采用“向最近偶数舍入”：结果选择距离最近的可表示值；如果正好处于两个值中间，选择最低有效位为偶数的那个。

采用该规则可以减少大量计算中的系统性偏差。

### 7. 浮点运算不满足结合律

由于每一步运算都可能舍入，浮点运算通常不满足数学中的结合律和分配律：

```text
(x + y) + z  可能不等于  x + (y + z)
(x × y) × z  可能不等于  x × (y × z)
x × (y + z)  可能不等于  x×y + x×z
```

例如，一个很大的数与一个很小的数相加时，小数可能在舍入中消失。因此计算顺序可能影响结果。

### 8. C 语言中的类型转换

- `int -> float`：可能发生舍入；`float` 的有效精度通常只有 24 位二进制位。
- `int -> double`：在常见范围内可以精确表示，`double` 通常有 53 位有效二进制精度。
- `float -> double`：通常不会再损失 `float` 已有的精度，但不能恢复原先已经丢失的信息。
- `double -> float`：可能舍入、溢出为无穷大或下溢。
- `float -> int`：通常朝 0 截断，例如 `(int)3.9` 为 `3`，`(int)-3.9` 为 `-3`；超出范围时不要依赖具体结果。

### 9. 常见陷阱

```c
5 / 2       // 整数除法，结果 2
5.0 / 2     // 浮点除法，结果 2.5
```

下面两种转换顺序也不同：

```c
(float)(a / b)       // 先整数除法，再转 float
(float)a / (float)b  // 先转换，再做浮点除法
```

不要默认以下表达式成立：

```c
0.1 + 0.2 == 0.3
```

涉及误差时，通常应使用误差范围比较，而不是直接比较相等。

## 一句话总结

> 浮点数用 sign、exponent 和 fraction 在有限位数中近似表示实数；它扩大了可表示范围，但引入精度和舍入问题，因此浮点计算不能完全按照实数运算的直觉理解。
