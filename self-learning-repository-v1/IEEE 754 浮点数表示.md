# IEEE 754 浮点数表示

## 核心观点

IEEE 754 用三部分位域表示浮点数：

```text
sign | exponent | fraction
```

其数值模型可以写成：

```text
V = (-1)^s × M × 2^E
```

## 解释

常见格式：

| 类型 | 总位数 | sign | exponent | fraction | bias |
|---|---:|---:|---:|---:|---:|
| `float` | 32 | 1 | 8 | 23 | 127 |
| `double` | 64 | 1 | 11 | 52 | 1023 |

规格化数中，尾数采用：

```text
M = 1.fraction
E = Exp - Bias
```

前导 `1` 不实际存储，称为隐含前导 1。

编码类别由 exponent 决定：

| exponent | fraction | 含义 |
|---|---|---|
| 全 0 | 全 0 | `+0` 或 `-0` |
| 全 0 | 非 0 | 非规格化数 |
| 非全 0、非全 1 | 任意 | 规格化数 |
| 全 1 | 全 0 | `+∞` 或 `-∞` |
| 全 1 | 非 0 | NaN |

非规格化数没有隐含前导 1，用于表示接近 0 的数，并支持渐进下溢。

## 例子 / 推导

```text
100.01₂ = 1.0001₂ × 2²
```

对于单精度：

```text
sign = 0
E = 2
Exp = E + Bias = 2 + 127 = 129
fraction = 0001...
```
