# 浮点运算不满足结合律

## 核心观点

由于每一步浮点运算都可能发生舍入，浮点加法和乘法通常不满足数学中的结合律，也不一定满足分配律。

```text
(x + y) + z  可能不等于  x + (y + z)
(x × y) × z  可能不等于  x × (y × z)
x × (y + z)  可能不等于  x×y + x×z
```

## 解释

数学运算可以假设无限精度，而浮点运算必须在有限位数的格式中保存中间结果。如果先计算一个很大的数和很小的数，小数部分可能在舍入时消失；改变括号或计算顺序，就可能得到不同结果。

因此，涉及数值精度时：

- 不要随意重排计算顺序；
- 不要直接用 `==` 比较有误差的计算结果；
- 需要根据误差范围设计比较；
- 注意编译器可能进行改变计算顺序的浮点优化。

## 例子 / 推导

```c
float a = 3.14f;
float b = 1e20f;

float x = (a + b) - b;
float y = a + (b - b);
```

`x` 和 `y` 可能不同，因为 `a + b` 时 `a` 可能在舍入中消失，而 `b - b` 可能先得到 0。
